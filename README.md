# Lost Client (Fabric 1.21)

Keys: Right Shift = menu, H = hide/show module list.

## Build the jar (pick one)
A) Local: install Java 21 + Gradle 8.8, then run build.bat (Windows) or ./build.sh
   -> build/libs/lostclient-0.1.0.jar
B) No installs: upload this folder to a GitHub repo. The "build" workflow
   (Actions tab) produces the jar as a downloadable artifact.

## Install
Put the jar and Fabric API (for 1.21) into .minecraft/mods, launch with Fabric Loader 1.21.
